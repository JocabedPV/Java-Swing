# Calculadora Extendida - Java Swing

Aplicación de escritorio en Java Swing con tres pestañas: calculadora (+, -, ×, ÷ con validación de división por cero), conversor de temperatura (°F ↔ °C) y raíz cuadrada/exponente.

## Cómo ejecutarlo

```
cd src
javac *.java
java Main
```

Requiere tener instalado el JDK.
